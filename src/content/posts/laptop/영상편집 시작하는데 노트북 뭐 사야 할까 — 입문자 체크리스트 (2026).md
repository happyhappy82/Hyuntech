## 영상편집에서 노트북이 해야 하는 일


영상편집 소프트웨어를 돌리려면 노트북의 여러 부품이 동시에 일해야 해요. 어떤 부품이 어떤 역할을 하는지 먼저 이해하면 선택이 훨씬 쉬워져요.


| 부품          | 역할                 | 영상편집에서의 중요도 |
| ----------- | ------------------ | ----------- |
| CPU (프로세서)  | 영상 인코딩, 타임라인 재생    | 매우 높음       |
| RAM (메모리)   | 동시 작업 처리, 프리뷰 버퍼   | 매우 높음       |
| GPU (그래픽카드) | 실시간 미리보기, 색보정, 이펙트 | 높음          |
| SSD (저장장치)  | 영상 소스 불러오기/저장 속도   | 높음          |
| 디스플레이       | 색감 확인, 편집 정확도      | 보통~높음       |


### 프로그램별 권장 사양

- **프리미어 프로**: CPU i7/라이젠7 이상, RAM 16GB 이상, GPU RTX 3050 이상
- **다빈치 리졸브**: GPU 의존도가 매우 높음. RTX 4050 이상 권장, RAM 16~32GB
- **파이널컷 프로**: 맥 전용 (M시리즈 칩 탑재 맥북)
- **캡컷/키네마스터**: 저사양으로도 가능 (모바일 앱 기반)
> 입문자라면 프리미어 프로나 다빈치 리졸브 중 하나를 기준으로 잡는 게 좋아요. 다빈치 리졸브는 무료 버전이 있어서 초기 비용 부담이 적어요.

### 중요한 스펙 vs 돈 낭비인 스펙

- **투자 가치 있음**: RAM 16GB→32GB 업그레이드, NVMe SSD, RTX 4050 이상 GPU
- **입문자에게 과한 스펙**: RTX 4070 이상 (4K 이상 전문 편집이 아니라면), 64GB RAM, 4K OLED 디스플레이
