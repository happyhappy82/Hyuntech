## 체크 1: 개발 분야에 맞는 핵심 스펙


모든 개발자에게 같은 노트북을 추천하는 건 의미가 없어요. 웹 프론트엔드와 머신러닝 개발자는 필요한 사양이 완전히 달라요.


| 개발 분야                | CPU        | RAM     | GPU         | 저장 장치     |
| -------------------- | ---------- | ------- | ----------- | --------- |
| 웹 프론트엔드              | i5/라이젠5 이상 | 16GB    | 내장 OK       | SSD 512GB |
| 웹 백엔드 (Docker 활용)    | i7/라이젠7 이상 | 16~32GB | 내장 OK       | SSD 1TB   |
| 모바일 앱 (Android)      | i7/라이젠7 이상 | 32GB 권장 | 내장 OK       | SSD 1TB   |
| 데이터/AI/ML            | i7/라이젠7 이상 | 32GB 이상 | RTX 4050 이상 | SSD 1TB   |
| 게임 개발 (Unity/Unreal) | i7/라이젠7 이상 | 32GB    | RTX 4060 이상 | SSD 1TB   |


### 핵심 포인트

- **Docker를 쓴다면 RAM이 핵심이에요.** 컨테이너 하나당 1~2GB씩 잡아먹으니, 여러 서비스를 띄우면 16GB도 빠듯해요.
- **Android 에뮬레이터는 RAM 괴물이에요.** Android Studio + 에뮬레이터를 동시에 돌리면 최소 12GB를 사용해요.
- **AI/ML이라면 외장 GPU가 거의 필수예요.** 로컬에서 모델 학습을 돌릴 일이 있다면 RTX 4050 이상이 필요해요.

## 체크 2: 작업 환경과 휴대성


프리랜서는 작업 장소가 고정되어 있지 않아요. 그래서 무게와 배터리가 회사원보다 더 중요할 수 있어요.

- **주로 집/사무실에서 외부 모니터 연결**: 화면 크기보다 성능에 투자. 15~16인치 OK
- **카페/공유오피스 중심**: 무게 1.5kg 이하, 배터리 8시간 이상 권장
- **클라이언트 미팅이 잦음**: 14인치급, 깔끔한 디자인, 빠른 부팅
> 외부 모니터를 쓰시는 분이라면 노트북 화면은 14인치로 가볍게 가고, 성능에 예산을 집중하는 전략도 좋아요.

## 체크 3: 키보드와 디스플레이


하루에 8시간 이상 타이핑하는 직업이잖아요. 키보드 타건감과 디스플레이 품질은 생산성에 직접 영향을 줘요.

- **키보드**: 키 트래블(눌림 깊이) 1.5mm 이상, 적당한 반발력. 구매 전 매장에서 직접 타이핑해보는 걸 추천해요.
- **디스플레이**: 16:10 비율이 코딩에 유리해요. 같은 화면 크기에서 세로 줄이 더 많이 보여요.
- **색재현율**: 코딩 위주라면 sRGB 100%면 충분. 프론트엔드에서 디자인 작업도 겸한다면 DCI-P3 지원이 좋아요.

---


## 체크 4: 확장성과 포트


프리랜서라면 외부 장비 연결이 많아요. 포트 구성은 생각보다 중요한 체크 포인트예요.

- **USB-C (Thunderbolt)**: 외부 모니터, 도킹 스테이션 연결 필수
- **USB-A**: 외장 키보드, 마우스, USB 메모리 등 레거시 장비용
- **HDMI**: 클라이언트 미팅에서 프로젝터 연결
- **RAM 슬롯**: 나중에 RAM 추가가 가능한지 확인. 온보드(납땜) 방식이면 구매 시 최대로 가야 해요.
- **SSD 슬롯**: 추가 SSD 장착이 가능하면 나중에 저장 공간 확장이 쉬워요.
