## 디자이너에게 노트북 선택이 어려운 이유


디자인 업무를 하시는 분이라면 노트북 하나 사는 게 보통 고민이 아니실 거예요. 포토샵으로 고해상도 이미지 편집하고, 일러스트레이터로 벡터 작업하고, 피그마로 UI 프로토타입 만들고. 이 작업들이 쾌적하게 돌아가려면 단순히 "비싼 거" 사면 되는 게 아니거든요. 색감이 정확하지 않으면 작업물이 클라이언트 모니터에서 전혀 다르게 보이기도 하고, GPU가 부족하면 레이어 많은 파일에서 버벅거리기도 해요.


이 글을 다 읽으시면 디자이너로서 노트북을 고를 때 어디에 돈을 써야 하고, 어디서 아껴도 되는지 명확하게 정리되실 거예요.


디자이너라고 하면 범위가 넓지만, 여기서는 **그래픽 디자이너, UI/UX 디자이너, 브랜드 디자이너** 등 시각 디자인 작업을 주로 하시는 분을 기준으로 정리했어요.

## 2. 구매 전 체크리스트


구매 전에 본인 상황에 맞춰 체크해보세요.

- [ ] **주로 어디서 작업하나요?**
    - 스튜디오/집 위주 → 무게보다 화면 크기와 성능 우선
    - 카페/미팅 이동 많음 → 1.5kg 이하 + 배터리 8시간 이상 권장
- [ ] **가장 무거운 프로그램이 뭔가요?**
    - 포토샵 + 일러스트레이터 동시 → RAM 16GB 최소, 32GB 권장
    - 피그마 위주 → RAM 16GB면 충분
    - 3D 작업 병행 → 외장 GPU 필수
- [ ] **색 정확도가 중요한 작업인가요?**
    - 인쇄물/브랜딩 → DCI-P3 95% 이상 필수
    - 웹/UI 위주 → sRGB 100%면 무난
- [ ] **예산 범위는?**
    - 100만원 이하 → 색재현율 타협 필요, sRGB 기준으로 선택
    - 100~180만원대 → 밸런스 좋은 구간
    - 200만원 이상 → 색재현율 + GPU + RAM 모두 잡을 수 있음
- [ ] **외부 모니터 사용 예정인가요?**
    - 예 → 노트북 화면은 14인치도 OK, 모니터 색감에 투자
    - 아니오 → 15~16인치 + 색재현율 높은 모델 필수

## 4. 흔한 실수 3가지


### 실수 1: "GPU 좋은 게이밍 노트북이면 디자인도 잘 되겠지"


게이밍 노트북은 GPU 성능은 좋지만, **디스플레이 색재현율이 낮은 경우가 많아요.** 게임에서는 색 정확도보다 주사율이 중요하거든요. 색감이 안 맞는 모니터로 디자인하면 인쇄물이나 클라이언트 화면에서 전혀 다르게 보일 수 있어요.


### 실수 2: "RAM 8GB로 시작하고 나중에 늘리면 되지"


포토샵과 일러스트레이터를 동시에 켜면 RAM 8GB는 금방 차요. 그리고 맥북이나 일부 울트라북은 **RAM이 메인보드에 납땜**되어 있어서 나중에 추가가 불가능한 경우도 많아요. 처음부터 16GB 이상으로 시작하세요.


### 실수 3: "화면 크면 무조건 좋겠지" → 무게 고려 안 함


17인치 노트북은 화면은 넓지만, 2.5kg 넘어가는 모델이 많아요. 미팅이나 카페 작업이 잦은 분이라면 16인치가 화면 크기와 휴대성의 균형점이에요.

## 5. 자주 하는 질문

<details>
<summary>디자이너는 맥북이 무조건 좋은가요?</summary>

무조건은 아니에요. 맥북은 디스플레이 색재현율, 트랙패드, 생태계 면에서 강점이 있지만, **윈도우 전용 프로그램을 써야 하거나 예산이 빠듯하다면** 윈도우 노트북이 더 합리적일 수 있어요. 특히 피그마는 웹 기반이라 OS 상관없이 동일하게 작동해요.


</details>

<details>
<summary>색재현율 DCI-P3와 sRGB 차이가 뭔가요?</summary>

sRGB는 웹 표준 색공간이고, DCI-P3는 더 넓은 색 범위를 표현할 수 있어요. 인쇄물이나 영상 작업까지 하신다면 DCI-P3 지원 모니터가 유리해요. 웹/UI 디자인만 하신다면 sRGB 100% 커버만 돼도 실무에 문제없어요.


</details>

<details>
<summary>외장 GPU가 꼭 필요한가요?</summary>

포토샵, 일러스트레이터, 피그마 위주라면 내장 GPU로도 충분해요. 다만 **3D 렌더링, 모션그래픽, 고해상도 영상 편집을 병행**하신다면 외장 GPU가 작업 속도에 큰 차이를 만들어요.


</details>

<details>
<summary>RAM 16GB와 32GB 중 어떤 걸 골라야 하나요?</summary>

포토샵 단독 작업이면 16GB로 충분해요. 하지만 **포토샵 + 일러스트레이터 + 브라우저(레퍼런스 탭 20개) 동시 사용**이 일상이라면 32GB를 강력하게 권장해요. 특히 맥북은 RAM 교체가 안 되니 처음부터 넉넉하게 선택하시는 게 좋아요.


</details>

<details>
<summary>중고 맥북으로 디자인 작업해도 괜찮을까요?</summary>

M1 이후 맥북이라면 중고도 괜찮아요. 다만 배터리 소모 상태와 RAM 용량을 꼭 확인하세요. Intel 맥북은 발열과 성능 면에서 현재 기준으로 추천하기 어려워요.


</details>

<details>
<summary>노트북만으로 충분한가요, 외부 모니터도 필요한가요?</summary>

가능하면 **색 보정된 외부 모니터를 하나 두시는 걸 추천**해요. 노트북 화면은 출장/미팅용으로 쓰고, 정밀한 색 작업은 모니터에서 하는 게 효율적이에요. 예산이 빠듯하다면 노트북 화면 색재현율이 높은 모델을 우선 선택하세요.


</details>
