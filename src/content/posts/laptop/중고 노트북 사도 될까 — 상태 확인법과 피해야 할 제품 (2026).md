## 중고 노트북, 정말 괜찮을까요


새 노트북은 부담되고, 중고로 사면 돈은 아끼는데 혹시 고장 나면 어쩌나 걱정되시죠. 특히 요즘 중고 시장이 워낙 커져서 매물은 많은데, 어떤 걸 골라야 하고 어떤 건 피해야 하는지 판단이 어려우실 거예요.


이 글에서는 **중고 노트북을 사도 되는 상황과 안 되는 상황, 그리고 상태를 직접 확인하는 구체적인 방법**을 정리해드릴게요. 결론부터 말씀드리면, 확인할 줄 알면 중고도 충분히 좋은 선택이 될 수 있어요. 하지만 모르고 사면 새 제품보다 비싼 값을 치를 수도 있어요.

## 판단 기준 프레임워크 — 중고를 사도 되는 상황 vs 피해야 할 상황


### 중고 노트북이 합리적인 경우

- 예산이 50만원 이하인데 기본 업무(문서, 인터넷)용이 필요한 경우
- 세컨드 노트북(보조용)이 필요한 경우
- 특정 브랜드/모델을 써보고 싶지만 새 제품이 단종된 경우
- 단기간(6개월~1년)만 쓸 예정인 경우

### 중고를 피해야 하는 경우

- 3년 이상 메인 노트북으로 쓸 계획인 경우
- 영상 편집, 코딩 등 고성능이 필요한 경우
- AS를 받을 수 있어야 마음이 편한 경우
- 노트북 상태를 직접 확인할 수 없는(택배 거래) 경우

## 중고 노트북 상태 확인 체크리스트


### 1. 배터리 사이클 확인 (가장 중요)


배터리는 중고 노트북에서 가장 먼저 열화되는 부품이에요.


**윈도우 확인법:**

- 명령 프롬프트에서 `powercfg /batteryreport` 입력
- "Design Capacity" vs "Full Charge Capacity" 비교
- Full Charge가 Design의 80% 이하면 배터리 교체가 필요해요

**맥북 확인법:**

- 시스템 정보 > 전원 > 사이클 수 확인
- 1000회 이상이면 배터리 수명이 다한 거예요

| 배터리 상태          | 판단              |
| --------------- | --------------- |
| 설계 용량 대비 90% 이상 | 양호              |
| 80~90%          | 1~2년 더 사용 가능    |
| 70~80%          | 배터리 교체 비용 감안 필요 |
| 70% 미만          | 비추천 (교체 비용이 큼)  |


### 2. 화면 불량 확인

- 흰색, 검정, 빨강, 초록, 파랑 전체 화면으로 데드픽셀 확인
- 화면 모서리 부분 빛샘(백라이트 블리드) 확인 — 어두운 환경에서 검정 화면으로 테스트
- 화면 열었다 닫았다 할 때 깜빡임이 있는지 확인

### 3. SSD 수명 확인

- CrystalDiskInfo(무료) 프로그램으로 확인
- "건강 상태"가 90% 이상이면 양호
- "총 호스트 쓰기"가 너무 크면(10TB 이상) 수명이 줄어든 거예요

### 4. 키보드와 트랙패드

- 모든 키를 하나씩 눌러서 입력 확인 (온라인 키보드 테스터 활용)
- 트랙패드 클릭감, 멀티터치 동작 확인
- 키캡 마모 상태로 실사용량을 짐작할 수 있어요

### 5. 포트와 외관

- 모든 USB 포트에 장치를 연결해서 인식 확인
- 충전 포트 헐거움 여부
- 힌지(화면 연결 부분) 뻑뻑하거나 헐거운지 확인
- 외관 찍힘, 긁힘은 기능에 영향 없으니 가격 협상 포인트로 활용

## 피해야 할 중고 노트북


### 연식 기준


| 출시 연도      | 추천 여부  | 이유             |
| ---------- | ------ | -------------- |
| 2024~2025년 | 추천     | 성능, 배터리 모두 양호  |
| 2022~2023년 | 조건부 추천 | 배터리 상태 꼼꼼히 확인  |
| 2021년 이전   | 비추천    | 부품 노후화, AS 어려움 |


### 피해야 할 모델 특징

- **RAM 8GB 온보드 모델**: 업그레이드 불가, 2026년 기준 부족해요
- **eMMC 저장장치 모델**: SSD가 아닌 eMMC는 속도가 매우 느려요
- **단종된 마이너 브랜드**: AS 불가, 부품 수급 어려움
- **게이밍 노트북 중고**: 고온에서 오래 사용된 경우가 많아 열화가 심해요
