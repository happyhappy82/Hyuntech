## 교사·강사에게 노트북이 고민되는 이유


수업을 하시는 분이라면 노트북이 단순한 문서 도구가 아니실 거예요. PPT 만들어서 프로젝터에 연결하고, Zoom으로 화상수업 진행하고, 학생 자료 관리하고, 성적 처리까지. 이 모든 게 끝나면 노트북 들고 다른 교실이나 강의장으로 이동해야 하고요.


이 글을 다 읽으시면 수업용 노트북을 고를 때 어디에 돈을 써야 하고, 어디서 아껴도 되는지 확실하게 정리되실 거예요.


여기서는 **초·중·고 교사, 학원 강사, 대학 강사, 외부 강사** 등 수업과 강의를 직접 진행하시는 분을 기준으로 정리했어요.

## 1. 이 직업에서 노트북에 요구되는 것


### 주로 사용하는 프로그램과 작업


| 프로그램/작업              | 요구 스펙              | 중요도 |
| -------------------- | ------------------ | --- |
| PowerPoint / 프레지     | 기본 CPU, RAM 8GB 이상 | 필수  |
| Zoom / Teams (화상수업)  | 웹캄, 마이크, 안정적 CPU   | 필수  |
| Word / 한글 (시험지, 학습지) | 기본 사양              | 필수  |
| Excel (성적처리, 학생관리)   | 기본 사양              | 중간  |
| 유튜브/교육용 영상 재생        | 기본 CPU + 및추어진 RAM  | 중간  |
| 프로젝터 연결 (HDMI/USB-C) | 포트 확인 필수           | 높음  |


### 진짜 중요한 스펙 vs 돈 낭비되는 스펙


| 스펙               | 중요도   | 이유                   |
| ---------------- | ----- | -------------------- |
| 무게/휴대성           | ★★★★★ | 교실 이동, 강의장 이동이 일상이에요 |
| 배터리              | ★★★★★ | 수업 중간에 배터리 떨어지면 난감해요 |
| 포트 (HDMI, USB-C) | ★★★★★ | 프로젝터 연결 가능 여부가 핵심이에요 |
| RAM              | ★★★☆☆ | 8GB면 충분, 16GB면 넉넉    |
| CPU              | ★★★☆☆ | 중간 등급이면 충분해요         |
| SSD              | ★★★☆☆ | 256GB도 가능, 512GB 권장  |
| GPU (외장)         | ★☆☆☆☆ | 수업용에는 완전히 필요 없어요     |
| 고주사율             | ★☆☆☆☆ | 게임용 스펙이에요. 돈 낭비      |


**핵심 정리:** 무게, 배터리, 포트에 돈을 쓰세요. GPU나 고주사율은 수업용에는 완전히 불필요해요.

## 2. 구매 전 체크리스트

- [ ] **프로젝터 연결이 필요한가요?**
    - 예 → HDMI 포트 내장 또는 USB-C to HDMI 어댑터 확인
    - 아니오 → 포트 덜 중요
- [ ] **화상수업을 진행하나요?**
    - 예 → 웹캄 화질 + 마이크 성능 확인, RAM 16GB 권장
    - 아니오 → RAM 8GB로도 충분
- [ ] **교실/강의장 이동이 잦은가요?**
    - 예 → 1.3kg 이하, 배터리 10시간 이상 권장
    - 아니오 (고정 자리) → 무게 덜 중요, 15인치 가능
- [ ] **예산 범위는?**
    - 50만원 이하 → 가성비 모델, 기본 수업 충분
    - 50~120만원대 → 가벼운 프리미엄 모델 선택 가능
    - 120만원 이상 → 초경량 + 장시간 배터리
- [ ] **학교/기관 지원이 있나요?**
    - 예 → 지원 범위 내에서 최적 모델 선택
    - 아니오 → 가성비 중심으로 선택

## 3. 확인해야 할 4가지 (본론)


### 확인 1: PPT가 버벥없이 돌아가는가


수업 자료를 PPT로 만드시는 분이 많을 거예요. 애니메이션이나 영상 삽입이 많은 PPT는 CPU와 RAM을 생각보다 많이 쓰는데요.

- **텍스트 + 이미지 위주 PPT** → CPU 기본 등급, RAM 8GB면 OK
- **영상/애니메이션 많은 PPT** → RAM 16GB 권장
- **프레지 같은 동적 발표 도구** → 안정적인 인터넷 + RAM 8GB 이상

수업 중간에 PPT가 멈추는 것만큼 난감한 일이 없어요. SSD 탑재 모델이면 프로그램 로딩도 빠르니까 확인해보세요.


### 확인 2: 화상수업(Zoom/Teams)이 원활한가


코로나 이후 화상수업이 일상이 된 분들이 많죠. Zoom이나 Teams로 수업하려면 몇 가지 체크할 게 있어요.

- **웹캄 화질:** FHD(1080p) 웹캄이 내장된 모델이 좋아요. HD(720p)는 화질이 떨어져요.
- **마이크:** 노이즈 캔슬링 기능이 있으면 주변 소음이 줄어들어요.
- **RAM:** Zoom + PPT 화면공유 + 브라우저 동시에 켜면 RAM 16GB가 편해요.
- **안정적인 Wi-Fi:** Wi-Fi 6 이상 지원 여부 확인.

### 확인 3: 프로젝터/디스플레이 연결이 되는가


교실이나 강의장에서 프로젝터에 연결해야 하는 경우가 많아요. 이게 안 되면 수업 자체가 어려워져요.

- **HDMI 포트 내장:** 가장 편해요. 어댑터 없이 바로 연결 가능.
- **USB-C (DP 출력 지원):** HDMI가 없는 엇은 노트북이면 USB-C to HDMI 어댑터 필요.
- **무선 연결 (Miracast 등):** 최신 프로젝터라면 가능하지만, 구형 프로젝터는 HDMI 유선 연결이 안정적.

**팁:** 학교/강의장 프로젝터가 HDMI만 지원하는 경우가 많으니, **HDMI 포트가 있는 모델**이거나 **어댑터를 꼭 챙겨두세요.**


### 확인 4: 들고 다니기 편한가


교실 간 이동, 강의장 이동, 잡아야 할 서류까지 있으면 노트북이 가벼운 게 중요해요.

- **무게 1.3~1.5kg 이하** 권장. 서류 + 노트북 + 책 합쳐서 백에 넣어야 하니까요.
- **배터리 10시간 이상.** 오전 수업 시작해서 오후까지 충전 없이 버퇸야 해요.
- **13~14인치** 사이가 밸런스 좋아요. 15인치는 조금 큰 대신 화면 넓고, 13인치는 작지만 가볼운.

## 5. 흔한 실수 / 자주 하는 질문


### 흔한 실수


**실수 1: "HDMI 포트 없는 엇은 노트북 샀더니 프로젝터 연결이 안 됨"**


최신 엇은 노트북은 HDMI 포트가 없는 경우가 많아요. 구매 전에 포트를 확인하고, 없으면 USB-C to HDMI 어댑터를 리스트에 추가하세요.


**실수 2: "배터리 좋다고 해서 샀는데 무거웠음"**


배터리 용량이 큰 노트북은 무게도 무거운 경우가 있어요. 무게와 배터리를 동시에 만족시키는 모델을 찾으세요.

<details>
<summary>맥북으로 수업해도 되나요?</summary>

PPT(키노트), Zoom, 브라우저 작업이 주라면 맥북도 좋아요. 다만 **한글(HWP) 문서가 많은 환경**이라면 윈도우가 안전해요. 또 프로젝터 연결 시 HDMI 어댑터가 필요하니까 미리 준비해두세요.


</details>

<details>
<summary>태블릿(iPad)으로 수업을 대체할 수 있나요?</summary>

보조 도구로는 좋지만 노트북을 완전히 대체하기는 어려워요. 특히 성적 처리(Excel), 문서 작성(한글), 프로젝터 연결 등에서 제약이 많아요.


</details>

<details>
<summary>RAM 8GB로 충분한가요?</summary>

PPT + Word 정도라면 8GB로도 가능해요. 하지만 Zoom 화상수업 + PPT 화면공유 + 브라우저 동시 사용이라면 16GB가 훨씬 여유롭어요. 예산 여유가 있다면 16GB를 권장해요.


</details>

<details>
<summary>프로젝터 연결용 어댑터는 다 되나요?</summary>

USB-C to HDMI 어댑터는 대부분 호환되지만, 간혹 노트북의 USB-C 포트가 **영상 출력(DP Alt Mode)을 지원하지 않는** 경우가 있어요. 구매 전에 스펙에서 "USB-C DP 출력" 지원 여부를 확인하세요.


</details>

<details>
<summary>수업용 노트북 추천 예산이 얼마인가요?</summary>

기본 수업용이라면 **60~80만원대**로도 충분해요. 휴대성까지 잡으려면 **120~160만원대** 초경량 모델을 고려해보세요.


</details>
