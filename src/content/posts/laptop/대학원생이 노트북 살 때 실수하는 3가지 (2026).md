## 대학원생에게 노트북이 유독 고민되는 이유


대학원 입학 앞두고 노트북 하나 새로 장만하려는데, 뭘 사야 할지 막막하시죠. 학부 때 쓰던 노트북으로 버텨볼까 싶다가도, 논문 쓰면서 SPSS 돌리고 R로 통계 분석하고 발표자료 만들고 하면 "이게 진짜 되나?" 싶은 순간이 올 거예요.


문제는 대학원생 예산이 넉넉하지 않다는 거예요. 그래서 "어디에 돈을 써야 하고, 어디서 아껴도 되는지"를 아는 게 중요해요. 이 글을 다 읽으시면 대학원 생활에 맞는 노트북을 고르는 기준이 명확하게 잡히실 거예요.


대학원생이라고 해도 전공마다 필요한 사양이 다르지만, 여기서는 **인문·사회과학, 경영, 교육, 이공계(코딩/통계 중심)** 대학원생을 기준으로 정리했어요.

## 1. 이 직업에서 노트북에 요구되는 것


### 주로 사용하는 프로그램과 작업


| 프로그램/작업                  | 요구 스펙                  | 중요도   |
| ------------------------ | ---------------------- | ----- |
| Word / 한글 / LaTeX        | 기본 사양이면 충분             | 필수    |
| SPSS / STATA             | RAM 8GB 이상, CPU 중요     | 높음    |
| R / RStudio              | RAM 16GB 권장 (대규모 데이터)  | 높음    |
| Python (Jupyter, pandas) | RAM 16GB 권장, SSD 속도 중요 | 중간~높음 |
| PowerPoint / 발표          | 기본 사양                  | 필수    |
| Zoom / Teams (화상)        | 카메라, 마이크, 안정적 CPU      | 중간    |
| 논문 PDF 다수 열기             | RAM 중요 (탭 30개 이상)      | 높음    |


### 진짜 중요한 스펙 vs 돈 낭비되는 스펙


| 스펙        | 중요도   | 이유                                      |
| --------- | ----- | --------------------------------------- |
| RAM       | ★★★★★ | SPSS + Word + 브라우저(논문 탭 20개) 동시에 돌려야 해요 |
| SSD 속도/용량 | ★★★★☆ | 논문 PDF, 데이터셋 저장 공간 + 프로그램 로딩 속도         |
| CPU       | ★★★★☆ | 통계 연산 속도에 직결돼요                          |
| 무게        | ★★★★☆ | 매일 연구실-강의실-도서관 이동해야 해요                  |
| 배터리       | ★★★★☆ | 도서관에서 자리 잡았는데 콘센트 없을 수 있어요              |
| GPU (외장)  | ★☆☆☆☆ | 딥러닝 전공 아니면 돈 낭비예요                       |
| 터치스크린     | ★☆☆☆☆ | 논문 작업에 쓸 일 거의 없어요                       |


**핵심 정리:** RAM과 SSD에 돈을 쓰세요. 외장 GPU는 딥러닝 전공이 아니면 필요 없어요.

## 2. 구매 전 체크리스트

- [ ] **전공에서 어떤 프로그램을 쓰나요?**
    - Word/한글 + SPSS 정도 → RAM 16GB면 충분
    - R/Python으로 대규모 데이터 분석 → RAM 16GB 필수, 32GB 권장
    - 딥러닝 학습 → 외장 GPU 필요 (이 글 범위 밖)
- [ ] **주로 어디서 작업하나요?**
    - 연구실 고정 → 무게 덜 중요, 화면 크게 가도 OK
    - 이동 잦음 (강의실-도서관-카페) → 1.5kg 이하 권장
- [ ] **예산 범위는?**
    - 70만원 이하 → 가성비 모델, RAM 16GB 확인 필수
    - 70~130만원대 → 가장 선택지 많은 구간
    - 150만원 이상 → 맥북 포함, 장기 사용 고려
- [ ] **외부 모니터 사용 예정인가요?**
    - 예 → 14인치도 충분, 모니터 연결 포트 확인
    - 아니오 → 15~16인치로 논문 양면 보기 편하게
- [ ] **배터리 얼마나 중요한가요?**
    - 도서관 장시간 작업 → 10시간 이상 모델 우선
    - 항상 콘센트 근처 → 배터리 덜 중요

## 3. 흔한 실수 3가지 (본론)


### 실수 1: "게이밍 노트북 사면 뭐든 잘 되겠지"


대학원 선배가 "게이밍 노트북 사면 성능 걱정 없어"라고 하는 경우가 있어요. 틀린 말은 아닌데, 대학원생한테는 안 맞는 경우가 많아요.

- **무게 2kg 이상:** 매일 들고 다니면 어깨 아파요
- **배터리 3~4시간:** 도서관에서 콘센트 없으면 끝이에요
- **팬 소음:** 강의실이나 도서관에서 민폐예요
- **외장 GPU:** SPSS, R에서는 GPU를 거의 안 써요. 돈만 더 들어요

**대안:** 같은 예산으로 가벼운 비즈니스 노트북 사면 RAM도 넉넉하고 배터리도 오래 가요.


### 실수 2: "RAM 8GB면 충분하지 않을까"


학부 때 과제용으로는 8GB로 버텼을 수 있어요. 하지만 대학원에서는 상황이 달라요.

- Word에 논문 80페이지 + 참고문헌 관리 프로그램(Zotero/Mendeley)
- SPSS 데이터셋 열어놓고 + 브라우저 탭 20개 (논문 검색)
- R에서 수만 행 데이터 불러오기

이걸 동시에 하면 8GB는 금방 한계에 부딪혀요. **16GB는 최소, 데이터 분석 많이 하시면 32GB 권장**이에요.


### 실수 3: "무거워도 성능 좋은 게 낫지"


연구실에만 있을 것 같지만, 실제로는 이동이 정말 많아요. 세미나실, 교수님 사무실, 도서관, 학회 출장까지. 2kg 넘는 노트북을 매일 들고 다니면 한 달 안에 후회해요.


**기준선:** 이동 많으면 1.3~1.5kg 사이, 연구실 고정이면 1.8kg까지 OK.

## 5. 자주 하는 질문

<details>
<summary>대학원생은 맥북 vs 윈도우 어느 쪽이 나은가요?</summary>

전공에 따라 달라요. LaTeX 중심 이공계, 개발 환경이 필요한 전공은 맥이 편해요. 반면 SPSS, 한글(HWP), 특정 통계 프로그램이 필수인 전공은 윈도우가 안전해요. 입학 전에 **연구실에서 주로 쓰는 OS가 뭔지** 선배한테 물어보세요.


</details>

<details>
<summary>SSD 256GB면 부족한가요?</summary>

부족할 가능성이 높아요. OS + 프로그램만 해도 100GB 이상 차지하고, 논문 PDF, 데이터셋, 발표자료가 쌓이면 금방 차요. **최소 512GB** 권장이에요.


</details>

<details>
<summary>학부 때 쓰던 노트북 그냥 써도 되나요?</summary>

RAM 16GB 이상이고 SSD 탑재된 모델이면 2~3년 더 쓸 수 있어요. 다만 RAM 8GB이거나 HDD 모델이면 SPSS 한 번 돌릴 때마다 스트레스 받으실 거예요. 부분 업그레이드(RAM/SSD 교체)가 가능한 모델인지 먼저 확인해보세요.


</details>

<details>
<summary>중고 노트북도 괜찮을까요?</summary>

예산이 빠듯하다면 중고도 방법이에요. 단, **배터리 소모 상태, RAM 용량, SSD 건강도**를 반드시 확인하세요. 2~3년 된 모델이면 크게 문제없지만, 5년 이상 된 모델은 배터리가 반나절도 안 갈 수 있어요.


</details>

<details>
<summary>대학원 가면 태블릿(아이패드)도 필요한가요?</summary>

논문 읽기와 필기용으로는 편하지만, 필수는 아니에요. 예산이 빠듯하면 노트북에 먼저 투자하세요. 태블릿은 나중에 필요할 때 추가해도 늦지 않아요.


</details>

<details>
<summary>외부 모니터가 있으면 작업 효율이 많이 달라지나요?</summary>

확실히 달라져요. 한쪽 화면에 논문, 다른 쪽에 Word 띄워놓고 작업하면 생산성이 올라가요. 연구실에 모니터가 있다면 노트북은 14인치 가벼운 모델 사고, 연구실에서는 모니터 연결해서 쓰는 것도 좋은 전략이에요.


</details>
