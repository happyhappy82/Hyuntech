## 1단계: Windows 업데이트 전체 실행


**경로**: 설정 → Windows 업데이트 → 업데이트 확인

- 가장 먼저 해야 할 일. 보안 패치 + 드라이버 + 기능 업데이트
- 업데이트 후 **재부팅 2~3회** 필요할 수 있음
- **24H2 버전** 확인: 설정 → 시스템 → 정보
- 소요 시간: 30분~1시간

## 5단계: 보안 설정


| 보안 기능             | 설정 경로             | 설명                    |
| ----------------- | ----------------- | --------------------- |
| **Windows Hello** | 계정 → 로그인 옵션       | 지문/얼굴 로그인             |

## 10단계: 배터리 80% 충전 제한 설정


리튜이온 배터리는 80~100% 구간에서 가장 빠르게 열화합니다. **80% 제한으로 수명 2~3배 연장**.


| 제조사       | 설정 방법                        | 충전 제한     |
| --------- | ---------------------------- | --------- |
| **삼성**    | Samsung Settings → 배터리 보호 ON | 최대 85%    |
| **LG 그램** | My gram → 수명 연장 모드           | 최대 80%    |
| **ASUS**  | MyASUS → 밸런스/최대수명 모드         | 80% / 60% |
| **레노버**   | Lenovo Vantage → 충전 임계값      | 사용자 지정    |
| **맥북**    | 시스템 설정 → 배터리 → 80% 제한        | 80%       |

> **팁**: 사무실에서 항상 전원 연결이면 **반드시 80% 제한**. 이동이 잦으면 필요 시 100% 충전.
