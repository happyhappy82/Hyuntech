## 각 항목별 확인 방법


### 1. 배터리


**Windows:**


`Win+R` → `cmd` → `powercfg /batteryreport` → HTML 파일에서 확인


**Mac:**


`Option` + Apple 메뉴 → 시스템 정보 → 전원


| 지표    | 양호      | 주의       | 회피          |
| ----- | ------- | -------- | ----------- |
| 사이클 수 | 300회 미만 | 300~500회 | **500회 이상** |
| 잔여 용량 | 80%+    | 60~80%   | **60% 미만**  |


### 2. 화면 불량화소


[deadpixeltest.org/ko](http://deadpixeltest.org/ko) 접속 → F11 전체화면 → 빨/록/파/흰/검 배경 순서로 전환하며 점 확인


### 3. SSD 수명


**Windows:** CrystalDiskInfo (무료) 설치 → 건강 상태 확인


**Mac:** Disk Utility → SMART 상태 확인


| 상태         | 의미        |
| ---------- | --------- |
| 좋음/Good    | 정상        |
| 주의/Caution | 교체 검토     |
| 나쁘/Bad     | **즉시 교체** |


### 4~8. 나머지 항목


| 항목    | 확인 방법                                |
| ----- | ------------------------------------ |
| 키보드   | 모든 키 눌러보기 (특히 스페이스바, Enter, Shift)   |
| 외관    | 모서리, 하판, 힌지 부분 꼼꼼히 확인                |
| 힌지    | 노트북 열고 닫을 때 느손함/사각거림 없는지             |

## FAQ


**Q1. 중고 노트북 거래 전 사기 여부를 확인하려면?**


A. 더치트([thecheat.co.kr](http://thecheat.co.kr/))에서 판매자 계좌번호·전화번호를 검색하세요. 경찰청 사이버안전국([ecrm.police.go.kr](http://ecrm.police.go.kr/))에서도 확인 가능합니다.


**Q2. CrystalDiskInfo를 중고 거래 현장에서 쓸 수 있나요?**


A. USB에 포터블 버전을 담아가면 설치 없이 바로 실행 가능합니다. 거래 전 판매자에게 확인을 요청하는 것도 방법입니다.


**Q3. 맥북 중고 구매 시 특별히 더 확인할 것은?**


A. 활성화 잠금(Activation Lock)이 해제되었는지 반드시 확인하세요. 전 소유자의 Apple ID가 남아있으면 사용할 수 없습니다.
