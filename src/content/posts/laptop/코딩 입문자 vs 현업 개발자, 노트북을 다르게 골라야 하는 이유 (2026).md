## 왜 다르게 골라야 하는가


### 입문자의 작업 패턴


코딩을 배우는 단계에서는 주로 이런 작업을 해요:

- 코드 에디터(VS Code 등)에서 간단한 코드 작성
- 웹 브라우저로 결과 확인
- 온라인 강의 수강
- 간단한 터미널 명령어 실행

이 정도라면 사실 **고사양이 전혀 필요 없어요.**


### 현업 개발자의 작업 패턴


현업에서는 상황이 완전히 달라요:

- IDE + 브라우저 탭 20개 + 터미널 여러 개 동시 실행
- Docker 컨테이너 3~5개 구동
- 로컬 서버 + DB 동시 실행
- Git, Slack, 화상회의 등 협업 도구 상시 실행

이 모든 게 동시에 돌아가니까, **RAM과 CPU가 곱절하게 필요해요.**

## 입문자 vs 현업 개발자 비교표


| 항목  | 코딩 입문자       | 현업 개발자                    |
| --- | ------------ | ------------------------- |
| CPU | i5/라이젠5 충분   | i7/라이젠7 이상 권장             |
| RAM | 8~16GB       | 16~32GB (분야에 따라)          |
| GPU | 내장 그래픽 OK    | AI/ML·게임개발시 외장 필요         |
| SSD | 256~512GB    | 512GB~1TB                 |
| 화면  | 14~15인치      | 15~16인치 (또는 외부모니터)        |
| 무게  | 가벼울수록 좋음     | 성능이 더 중요                  |
| 예산  | 50~100만원     | 100~200만원                 |
| 포트  | USB-C 1개면 OK | Thunderbolt, USB-A 등 다양해야 |


### 핵심 차이: RAM


가장 큰 차이는 RAM이에요. 입문자는 VS Code 하나만 켤도 문제없지만, 현업 개발자는 여러 프로그램이 동시에 돌아가니까 RAM이 부족하면 작업 효율이 급격히 떨어져요.

- Docker 컨테이너 1개당 약 1~2GB RAM 사용
- Chrome 탭 1개당 약 200~500MB RAM 사용
- Android 에뮬레이터는 최소 4GB RAM 점유
