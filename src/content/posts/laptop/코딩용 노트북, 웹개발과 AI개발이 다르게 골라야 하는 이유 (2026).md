## 같은 코딩용인데, 웹개발과 AI개발은 왜 다른 노트북이 필요할까요?


"코딩용 노트북 뭐가 좋아요?"라는 질문, 개발자 커뮤니티에서 가장 자주 올라오는 질문 중 하나예요. 그런데 이 질문에 한 가지 답을 내기가 어려운 이유가 있어요. **웹개발**과 **AI개발**은 같은 "코딩"이라는 이름이지만, 노트북에 요구하는 스펙이 근본적으로 다르거든요.


웹개발은 코드 에디터, 브라우저, 터미널을 동시에 띄우면서 CPU와 RAM이 중요하고, 내장 GPU로도 충분해요. 반면 AI개발은 모델 학습을 위해 GPU(특히 CUDA 지원 NVIDIA GPU)가 거의 필수이고, RAM도 32GB 이상이 권장돼요.


오늘은 이 두 상황을 명확하게 구분해서, 각각에 진짜 필요한 스펙과 추천 제품을 정리해 드릴게요.


---


## 왜 다르게 골라야 하나요?


코딩이라고 하면 다들 검은 화면에 코드 치는 모습을 떠올리시는데, 실제로 노트북에 걸리는 부하는 "무슨 코딩을 하느냐"에 따라 천차만별이에요.


**웹개발자**의 일반적인 작업 환경:

- VS Code 또는 WebStorm + 터미널 2~3개
- Chrome 탭 10개 이상 (개발자 도구 포함)
- 로컬 서버 (Node.js, Docker 컨테이너 등)
- Git 작업, Figma 참조
- CPU 멀티코어 + RAM 16GB면 쾌적

**AI개발자**의 일반적인 작업 환경:

- Jupyter Notebook 또는 VS Code + Python
- PyTorch / TensorFlow 모델 학습
- GPU 연산 (CUDA 필수)
- 대용량 데이터셋 로딩 (RAM 32GB+ 권장)
- 학습 중 GPU 풀 로드 장시간 지속

웹개발은 코드를 작성하고 브라우저에서 결과를 확인하는 사이클이라 CPU 반응 속도가 중요하고, AI개발은 모델 학습이라는 대규모 연산 작업이 핵심이라 GPU 성능이 가장 중요해요.


이걸 구분하지 않고 "개발자니까 맥북이면 되지"라고 단순화하면, AI개발자가 맥북에서 CUDA를 못 써서 고생하거나, 웹개발자가 쓸데없이 무거운 게이밍 노트북을 사게 되는 일이 벌어져요.

## 상황 A: 웹개발자에게 맞는 노트북


웹개발자에게 중요한 건 **빠른 CPU, 넉넉한 RAM, 좋은 키보드와 디스플레이, 그리고 휴대성**이에요. 하루 종일 코드를 치는 만큼 키보드 타건감이 실제 생산성에 크게 영향을 미치고, 코드와 브라우저를 나란히 띄워야 하니 화면이 넓을수록 유리해요.

## 자주 묻는 질문

<details>
<summary>맥북으로 AI개발이 아예 불가능한가요?</summary>

불가능하지는 않아요. Apple Silicon의 MPS(Metal Performance Shaders)를 PyTorch가 지원하기 시작했고, MLX 같은 Apple 전용 프레임워크도 있어요. 하지만 CUDA 생태계에 비하면 라이브러리 지원, 커뮤니티, 튜토리얼이 훨씬 적어요. 입문 단계에서 맥북으로 시작하면 호환성 문제로 시간을 많이 뺏길 수 있어서, CUDA 환경을 추천드리는 거예요.


</details>

<details>
<summary>웹개발인데 RAM 8GB로도 되나요?</summary>

2026년 기준으로는 어렵다고 봐야 해요. Chrome 탭 + VS Code + Docker만 동시에 띄워도 RAM 10GB를 쉽게 넘겨요. 최소 16GB, 여유 있게 하려면 32GB를 추천해요.


</details>

<details>
<summary>코딩용 노트북에서 디스플레이가 왜 중요한가요?</summary>

하루 8시간 이상 모니터를 보면서 코드를 작성하기 때문에, 해상도가 낮으면 글자가 흐릿하게 보여 눈이 빨리 피로해져요. 최소 FHD(1920x1080), 가능하면 QHD(2560x1440) 이상을 추천하고, 외장 모니터를 함께 쓰시면 생산성이 크게 올라가요.


</details>

<details>
<summary>리눅스를 설치할 건데 호환성에 문제없나요?</summary>

LG 그램, 델, 레노버, HP 모델 대부분이 Ubuntu 설치 호환성이 좋아요. 다만 최신 모델의 경우 Wi-Fi 드라이버나 지문인식 센서가 바로 잡히지 않는 경우가 있어서, 구매 전에 해당 모델의 Linux 호환성 후기를 확인하시는 게 좋아요.


</details>

<details>
<summary>노트북으로 AI 학습을 돌리면 수명에 영향이 있나요?</summary>

솔직히 영향이 있어요. GPU를 장시간 풀 로드로 돌리면 발열이 높아지고, 이게 반복되면 배터리 수명과 내부 부품 수명에 영향을 줄 수 있어요. 노트북으로 학습을 자주 돌린다면, 반드시 냉각 패드를 사용하고, 전원에 연결한 상태에서 작업하시는 걸 권장해요.


</details>

<details>
<summary>클라우드 GPU를 쓰면 노트북 GPU가 필요 없지 않나요?</summary>

맞는 말이에요. Google Colab, AWS SageMaker, Lambda Cloud 등을 활용하면 노트북 GPU 없이도 AI 학습이 가능해요. 하지만 클라우드는 비용이 지속적으로 발생하고, 네트워크 의존성이 있어요. 빠른 프로토타이핑과 디버깅은 로컬 GPU가 있으면 확실히 편하고요. 예산이 허락한다면 로컬 GPU + 클라우드 병행이 가장 효율적인 워크플로우예요.


</details>
